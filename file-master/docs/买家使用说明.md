# 使用说明

## 一、打开软件

双击 `LandcFileMaster.exe` 就能用，**不需要安装**。

想放桌面就右键 → 发送到 → 桌面快捷方式。

> **关于 WebView2**
> 软件界面用的是系统自带的「Microsoft Edge WebView2」组件。Windows 11 全部自带，
> Windows 10 绝大多数也已经内置，**正常情况下你什么都不用管，直接就能打开**。
>
> 万一你的系统里没有这个组件（多见于精简版系统、企业版 LTSC），双击后软件会弹出一个
> 中文提示窗告诉你缺什么，点「确定」会打开微软官方下载页，下载「Evergreen Bootstrapper」
> 双击装一下（约 1 分钟），然后再打开软件就行。不会出现「双击没反应」的情况。

## 二、三步完成批量改名

### 第 1 步：添加文件夹

点左上角 **添加文件夹**，选中要处理的目录。选中的目录下所有文件会列在右侧列表里。

可以分多次添加多个文件夹，列表上方会显示 **来源文件夹** 和每个目录下的文件数。
点文件夹后面的 `×` 可以把它从列表里去掉（**只影响列表，不会删磁盘上的任何文件**）。

### 第 2 步：设规则，看预览

左侧「批量改名」里设规则，右边列表会**实时**显示改完以后叫什么名字：

```
原文件名              预览结果
IMG_2041.JPG    →    2024旅行_001.JPG
IMG_2042.JPG    →    2024旅行_002.JPG
```

蓝色高亮的是会变的部分，一眼就能看出改动对不对。

**这时候还什么都没改**，文件都还是原来的名字。

### 第 3 步：点「立即改名」

确认预览没问题后，点左侧规则面板最下方的 **立即改名** 按钮（按钮上会显示即将改动的数量）。几秒钟就改完了。

### 只想改其中几个？

用鼠标点行、或勾选左边的复选框，**只有勾选的文件会被处理**。勾选后：

- 其余行会自动变淡，一眼就能看出这次只动哪几个
- 「立即改名」按钮上的数字会跟着变
- 一个都不勾 = 处理全部文件

如果列表里混了多个文件夹的文件，看 **所在位置** 这一列就知道每个文件来自哪个目录；
鼠标停在任意一行上会显示它的完整路径，双击该行可以直接在资源管理器中定位到它。

## 三、常用玩法

| 想做的事 | 怎么设 |
| --- | --- |
| 去掉文件名里的「副本」「(1)」 | 查找填 `副本`，替换留空 |
| 所有文件加统一前缀 | 前缀填 `2024项目_` |
| 按顺序编号 | 打开「自动编号」，补零填 3 → 得到 001、002、003 |
| 去掉文件名里的括号 | 剔除字符填 `【】()（）` |
| 全部改成小写 | 大小写选「全部小写」 |
| 把 .jpeg 全改成 .jpg | 切到「后缀转换」，选「替换」，填 `jpg` |
| 批量改文件创建时间 | 切到「时间属性」，选「设为指定时间」 |
| 把文件设为隐藏 | 切到「文件属性」，隐藏选「设为 是」 |
| 给一批 MP3 统一歌手 / 专辑 | 切到「标签编辑」，勾「作者」「专辑」后填值 |
| 给一批文档统一标题 / 作者 | 切到「标签编辑」，勾「标题」「作者」后填值 |

### 高级：正则替换

打开「正则表达式」开关后，可以做更复杂的替换。例如把 `第01集`、`第02集` 改成 `S01E01`：

- 查找：`第(\d+)集`
- 替换：`S01E$1`

其中 `$1` 代表括号里匹配到的数字。

## 四、批量编辑标签（文档属性 / 音乐标签）

切到左侧 **标签编辑**，可以改文件里「属性」那一栏的内容。

### 支持哪些格式

| 文件类型 | 能改的字段 |
| --- | --- |
| docx / xlsx / pptx | 标题、作者、主题、关键词、备注 |
| PDF | 标题、作者、主题、关键词、创建程序 |
| MP3 / FLAC / M4A / WAV / OGG 等音频 | 歌名、歌手、专辑、流派、年份、备注 |
| JPG / PNG / TIFF / WebP / HEIC 图片 | 备注（描述）、作者、版权、创建程序 |

### 怎么操作

1. 先在列表里**勾选**要处理的文件（不勾 = 处理全部）
2. 在字段前面**打勾**表示「这个字段要改」，然后填新值
3. 点底部「应用 N 项到 M 个文件」

没打勾的字段一律保持原样。

> **勾了但留空 = 清空该字段**。这是故意的：只勾一半的字段最安全。

### 两个细节

- **保留修改时间**（默认开）：改完把文件修改时间还原。批量打标签通常是整理动作，
  不该让一批老文件在资源管理器里全变成「今天」。
- **混格式批量**：比如同时勾了 docx 和 mp3，界面会显示两种格式支持字段的并集。
  对某个文件不适用的字段（如「专辑」对 docx）会自动忽略，只写它能接受的字段；
  如果某个文件一个字段都用不上，会记为该文件失败并在提示里报数量。

## 五、改错了怎么办

**点左侧「撤销历史」，找到刚才那次操作，点「撤销」。**

文件会恢复成操作前的名字。每次批量操作都会自动记录，可以撤销最近 100 次。

## 六、几个实用的保护机制

- **不会覆盖文件**：如果改完会和已有文件重名，软件会标红并**禁止执行**，不会把你的文件冲掉
- **不会改坏路径**：几百个文件互相改名（A→B、B→C）也能正确处理，不会丢文件
- **可以随时停**：改到一半发现不对，点状态栏的「停止」

## 七、常见问题

**Q：提示「文件正被其他程序占用」？**
把打开这些文件的程序（Word、播放器、资源管理器预览窗格）关掉再试。

**Q：杀毒软件报毒？**
这是没有购买数字签名的个人软件常见情况。软件不联网、不上传任何数据，所有操作都在本机完成。加入信任即可。

**Q：能处理多少个文件？**
单次建议 5 万个以内。列表用了虚拟滚动，10 万个也不卡，但改名本身受硬盘速度限制。

**Q：会动我的文件内容吗？**
改名、改时间、改属性只动文件的「外壳」，文件内容一个字节都不碰。

「标签编辑」会改写文件里的元数据区（Office 的 docProps、PDF 的 Info 字典、音频的标签块、
图片的 EXIF）。这是文件格式本来就留给属性的位置，不影响文档正文、画面和音质。
写入采用「先写临时文件、成功后再替换」的方式，中途断电或出错不会让原文件变成半截。

**Q：设置会保存吗？**
撤销记录保存在 `%APPDATA%\landc.file.master`，主题选择保存在本地。删掉这个目录等于恢复出厂设置。
