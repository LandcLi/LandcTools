**先说最关键的：这软件不会把你的文件搞坏。**

✅ **改之前先给你看结果** —— 左边改规则，右边实时显示改完长什么样，蓝色标出变化的部分，确认无误再点执行

**功能清单**

📝 **批量改名**
- 查找替换（支持正则，能提取数字、日期）

- 自动编号：001、002、003，可设起始值和位数
- 大小写转换、去空格、全角转半角

⏰ **批量改时间**
- 创建时间、修改时间、访问时间都能改
- 支持「统一设成某个时间」或「整体往前/往后挪几天」
- 整理素材、相册归档、按时间排序的场景特别好用

🔧 **批量改属性**
- 只读、隐藏、系统、存档，四个属性独立控制

📄 **批量换后缀**
- `.jpeg` 全改 `.jpg`、后缀统一大小写、多级后缀 `.tar` → `.tar.gz`

- MP3 / FLAC / M4A / WAV：歌名、歌手、专辑、流派、年份一次改完，不用一首首点

- 改完可以选保留文件修改时间，不会让整批文件全变成「今天」
